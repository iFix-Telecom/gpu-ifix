<threat_model>
Attack surface: dashboard controls that write two budgets which gate paid-pod teardown.
- **Privilege bypass:** the write path is owner-gated server-side (Phase 17 `requireOwner`
  in the server action, value-vs-bound validation before the gateway PATCH). This plan adds
  NO new route/action — it reuses that gated path, so an operator cannot write these budgets
  even by crafting a request (the server action re-checks owner + bound). No admin key
  reaches the browser (leak-guard: key only in {route.ts, gateway-admin.ts}).
- **Bad-value burn:** a slider set to an extreme within-bounds value is capped by the seeded
  bounds (min 30 / max 600 from 20-01) and by the untouched `coldstart_budget_s` ceiling.
- **Client/server key drift:** if a TS key name mismatches the gateway JSON, the slider
  silently binds `undefined` and could PATCH garbage. Mitigated by the acceptance requiring
  byte-for-byte key match with config_read.go + tsc.
</threat_model>
