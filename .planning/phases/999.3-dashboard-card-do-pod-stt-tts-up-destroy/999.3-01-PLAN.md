## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| ops-claude → gateway `/admin/sttpod/state` | Blob JSON não confiável cruza a rede pública; autenticado por X-Admin-Key mas o CONTEÚDO é dado externo |
| dashboard server action → gateway `/admin/sttpod/command` | Campo `command` originado de clique de UI; revalidado no servidor |
| gateway → Redis `gw:sttpod:*` | Espelho de estado sem persistência; único cliente é o gateway |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-999.3-02 | Tampering | `SttPodHandler.PostCommand` | mitigate | Whitelist fechada `{provision,destroy}` no handler Go; valor gravado é montado no servidor (`command` + `requested_at`), NUNCA o body do cliente verbatim |
| T-999.3-03 | Denial of Service | `SttPodHandler.PostState` | mitigate | `http.MaxBytesReader` de 256 KiB por request (o cap global de 25 MiB é grande demais) + `json.Valid` antes de gravar; teste `TestSttPodPostState_BodyTooLarge` |

| T-999.3-08 | Spoofing | rotas `/admin/sttpod/*` | transfer | `admin.Middleware` (X-Admin-Key, bcrypt) já monta em todo `/admin/*`; nenhum código de auth novo neste plano (D-04). O wiring do subrouter é do plano 999.3-02 |
